# Демонстрация A2 UI и V2

Запустите приложение в demo по README (`DEMO_MODE=1`). Ключ, сеть и расходы
OpenAI для этого сценария не требуются. A/B хранятся в сессии браузера.

1. «Заполнить пример из задания» → «Рассчитать и сохранить A».
   A: M7/Нура, M8/Нура, M10/Нура, M12/город, M5/Сарыарка.
   Стоимость 95, остаток 5, Score 56.54307, Ncrit=0.
2. Оставьте ограничение 1 и пустые закрепления. «Проверить план A»:
   20 проверок, completed_limited / improved. B заменяет M5/Сарыарка на M11/Нура.
   B: стоимость 80, остаток 20, Score 56.69056, Ncrit=0; выигрыш над A +0.14749.
   Это лучший из проверенных вариантов, не доказательство глобального оптимума.
3. Раскройте журнал и сравнение. Ухудшения: Сарыарка E2 48.75→40,
   C1 47.5→45; Нура T1 55→53.25. В Нуре B2 51.75→62.25.
4. В 3D: Транспорт → T1, «Только различия», переключите A/B.
   Выделена Нура, цифры 55/53.25, Δ=-1.75; камера сохраняется.
   Нажмите «Все районы», затем Нура. Под макетом в B виден M11 и эффект T1=-1.75.
   Слой «Безопасность», B2 показывает 51.75/62.25 и Δ=+10.5.
5. Измените M7 на M3 в черновике: стоимость 101. Расчёт A или ручного B
   отклоняется; сохранённые A/B и сцены остаются прежними.
6. Верните пример. «Рассчитать черновик как B» создаёт ручной B, равный A;
   ревизия очищается, A остаётся. В 3D различий нет. «Оставить A» удаляет B.
7. Измените район M7 на Есиль и рассчитайте черновик как B: это ручная альтернатива.
   Не нажимайте принятие, если хотите сохранить A. «Оставить A» сохраняет также черновик.
8. Верните пример и повторите ревизию. «Принять B как новый A» явно заменяет A,
   переносит решения B в черновик, очищает B/ревизию/объяснение/ограничения.
   Стоимость нового A и черновика 80, Score 56.69056.
9. Установите максимум замен 0 и запустите проверку: 0 новых кандидатов,
   «В проверенных вариантах улучшений нет». B равен A. Это ограниченная проверка.
10. Изменение любого ограничения очищает прошлые B/ревизию. При неполной ревизии
    UI отдельно показывает незавершённость и уже найденный результат/предупреждение.

При сбое WebGL можно переключать состояния и смотреть таблицы. Кнопка
«Повторить 3D» повторяет создание сцены. Браузерная проверка V2 выполнена также
на изолированном стенде с реальной потерей контекста и запретом WebGL; данные
A/B оставались доступны. Платный live и физический pinch не проверялись.

Автоматические проверки: `python run.py --check`; из `components/city3d/frontend`:
`npm test`, `npm run build`. Итог пакета: 181 Python и 16 JS тестов.
