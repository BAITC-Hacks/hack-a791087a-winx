# План реализации — «Аким: два будущих города»

Обновлён по `d454f61`. Пользователь установил обязательное требование: веб-приложение должно включать работающую 3D-сцену. Этот план задаёт этапы по зависимостям; календарные окна и старые правила сокращения объёма не являются критериями отказа от функций. Статусы отражают известное состояние на указанном коммите и не означают, что незавершённая реализация готова.

Подробные файлы, контракты и алгоритмы: [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md). Спецификация продукта: [PROPOSAL.md](PROPOSAL.md). Официальные правила: [TASK.md](TASK.md), [DATASET.md](DATASET.md).

Стек: Python + Streamlit + OpenAI API и локально собранный Three.js. Запуск: `python run.py`. Архитектура: форма → engine → валидированный результат → AI/UI и сцена. Все числа производит engine; AI объясняет и предлагает идентификаторы, а каждый кандидат проходит engine.
