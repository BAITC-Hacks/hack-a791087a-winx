# Проверка репозитория, плана и этапов E1/E2

23 сентября 2026. Зона @alikhan; база напарника `d12ac6a`.

## Репозиторий и план

- При начале проверки `python run.py --check` прошёл 15 тестов. Работали
  исходный экран, baseline и demo; validate_scenario/simulate оставались заглушками.
- PLAN и IMPLEMENTATION_PLAN соответствуют TASK/DATASET: ровно пять решений,
  бюджет 100, максимум две меры направления, три конфликта и три синергии.
  Указанные наборы стоимостью 61, 95, 100 и 101 посчитаны корректно.
- E1 → E2 можно завершить независимо от U1. Форма, сквозной UI, объяснение
  последствий и 3D остаются отдельными этапами напарника. После E2 наша задача — C0.
- Действующего API v1 достаточно для E1/E2; общие типы менять не требуется.
  Уточнены два неоднозначных места API: сочетания ошибок неизвестной меры/района
  и составной ключ сортировки effects, включая синергии и индикаторы.
- Условия готовности последующих этапов сохранены: 3D обязателен,
  ограниченный поиск не доказывает глобальный оптимум, AI не рассчитывает числа.

## E1 — выполнено

`citysim/engine.py` валидирует все правила, возвращает все применимые ошибки,
отклоняет невалидный набор до расчёта Score. Расчёт применяет лаги и синергии,
ограничивает итоговые показатели в [0,100], возвращает новые данные и трассировку.

В `tests/test_engine.py` 21 тест. Перед реализацией новые тесты падали на
NotImplementedError, три исходных теста проходили; после реализации проходят все.
Полный `python run.py --check` после E1: 33 теста OK, включая существующие AI/UI/launcher.

| Проверка | Результат |

| Baseline | Score 52.55768, Ncrit=2 |
| M7/Нура, M8/Нура, M10/Нура, M12/город, M5/Сарыарка | cost=95, remaining=5, Score=56.54307, Ncrit=0 |

## E2 — выполнено

`tests/test_engine_boundaries.py`: 12 тестов, включая случаи на копиях датасета
в памяти. Продуктовые данные не изменены. Дополнительных исправлений engine
по результатам E2 не потребовалось.

- Бюджет 100 принят, 101 отклонён (проверка 101 находится в test_engine.py).
- Результат ровно 40 не критичен; 39.999 критичен. Проверено после применения мер.
- Лаги 1/2/3/4, городские и районные эффекты; все три фиксированных бонуса +2.
- M11: T1=-1.75, B2=+10.5; три конфликта учитываются и при повторных строках.
- Clip до 0 и 100 выполняется только после суммы разнонаправленных эффектов;
  тесты отличают этот порядок от ограничения после каждой меры.
- Effects сохраняет прибавки до clip, deltas соответствуют фактическим изменениям.
  Проверены источники синергий, канонический порядок и независимость словарей
  before/after, исходного датасета и результатов разных запусков.

Итог: `python run.py --check` — **45 тестов OK**, включая AppTest и offline AI;
`.venv/Scripts/python.exe -m pip check` — **No broken requirements found**.
