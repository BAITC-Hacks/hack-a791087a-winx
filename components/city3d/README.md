# Прототип города в 3D

Запуск из корня проекта: `python run.py`. Node.js для обычного запуска не нужен:
готовые `build/city3d.js`, `build/city3d.css` и лицензия входят в комплект.
Прототип использует исходные показатели официального датасета через `baseline`.
API-ключ и платные запросы для 3D не нужны.

## Проверка вручную

1. Выбрать S1: Нура — 38, ниже 40; Есиль — 48. Базовый Score — 52.5577.
2. Выбрать Есиль кнопкой или объектом: карточка показывает 48 и районный балл 62.9900;
   подпись Streamlit под сценой подтверждает обратную передачу выбора.
3. Сменить показатель на E1: в Есиле 68. Геометрия города остаётся той же.
4. Повернуть/приблизить сцену, переключить район; проверить сохранение камеры.
   «Сверху» и «Общий вид» задают явные положения, +/− меняют масштаб.
5. На узком экране карточка переходит под макет; кнопки районов доступны с клавиатуры.
6. При отсутствии/потере WebGL показывается сообщение, карточка и таблицы остаются
   доступны. Реальную потерю контекста следует дополнительно проверить в браузере
   при финальной приёмке V1; автоматические тесты не заменяют её.

Макет условный: положение районов, количество и высота зданий не являются данными.
Только столбцы отражают выбранный показатель по общей шкале 0–100; риска — порог 40.
Оранжевый столбец обозначает значение <40; точные числа подписаны текстом.
Вид не показывает реальную географию, прогноз строительства или квартальную динамику.

## Разработка

Из `components/city3d/frontend`:

```sh
npm ci
npm test
npm run build
```

Используется Node.js 24; проверены Three.js 0.186.0 и Vite 8.3.0.
Сборка включает Three.js и OrbitControls: динамических CDN-импортов нет.
После изменения JS/CSS пересобрать компонент и перезагрузить страницу;
при сохранении старой сборки в сессии — перезапустить Streamlit.
`frontend/node_modules` исключён вложенным `.gitignore`; `build` сохраняется в Git.

`ui/scene.py` строит копию готового результата и проверяет входящие district_id.
`__init__.py` регистрирует локальную сборку через Streamlit Components v2.
`frontend/src/main.js` владеет DOM и событиями, `scene.js` — WebGL и камерой.
Renderer обновляется по взаимодействиям/resize без бесконечного animation loop;
при удалении освобождает геометрию, материалы, observer и обработчики событий.

Прототип поддерживает baseline с полями опубликованного ScenePayload v1 (C0).
Полная поддержка C0 — снимки A/B, снятие выбора, нормализация событий и проверка
версии протокола — остаётся частью V1/V2. Меры в сцене и итоговая приёмка не закрыты.

## Проверено

70 Python-тестов и 4 JS-теста после синхронизации с E2/C0: данные, селекторы, изоляция словарей, камера, границы
жестов. В in-app Chromium проверены настоящий WebGL, выбор района с ответом Python,
переключение S1/E1 и компоновка при ширине 390 и 1280 px. Физический pinch на телефоне
не проверен; его защита от ложного выбора покрыта тестом последовательности событий.
